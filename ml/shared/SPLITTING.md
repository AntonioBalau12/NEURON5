# Shared 70/20/10 split and 10-fold CV

`splits.csv` maps every practice row ID exactly once to `train`, `validation`, or `test` (seed 42), with a group-stratified 70/20/10 outer split. `cv10_folds.csv` maps each outer-train row ID to one of 10 grouped folds; rotate one fold as validation and use the other nine for training. The outer test rows are excluded from CV and should be evaluated once after model selection. The split and folds use greedy assignment of indivisible groups. Groups join normalized duplicate text, identical canonical fact signatures, and character-trigram near duplicates with Jaccard >= 0.90. Broad subject/attribute histories are audited separately instead of grouped: joining every claim sharing a history creates giant components and makes the requested partitions unusable. `splitting_audit.json` reports history overlap across outer partitions and CV folds; temporal generalization should be interpreted with this leakage in mind. Gold forms are used only for duplicate grouping and audit, never as inference features.

The assignment balances TRUE/FALSE/UNSURE counts and total row counts against the target ratios. Date ranges are audited rather than used to force chronological partitions. Training-only evidence is not used in the split.

Reproduce with `uv run --no-project --with numpy==2.2.6 --with scipy==1.15.3 --with scikit-learn==1.6.1 python ml/shared/create_splits.py`. The manifest has columns `id,split`; the fold file has columns `id,fold`. The folds use scikit-learn `StratifiedGroupKFold`.
